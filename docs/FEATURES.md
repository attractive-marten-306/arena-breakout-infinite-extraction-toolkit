# Arena Breakout: Infinite Extraction Toolkit — feature reference

A extraction toolkit workspace for Arena Breakout: Infinite, built around equipment plans and map references, with session records kept in a separate reference area.

| Section | Description |
|---|---|
| Equipment plans | Equipment categories and the associated selection or configuration options. |
| Map references | A dedicated section for map references and the configuration details associated with that area. |
| Session records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
